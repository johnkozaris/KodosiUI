# UI Don'ts

This file is a binding design constraint for every Kodosi UI surface. Do not
introduce, preserve, or normalize any of the following patterns. They make the
product look generic, template-driven, or "vibecoded" instead of authored.

1. Purple-to-blue gradients
2. Gradient hero text
3. Emojis in headings
4. Inter used as the default font everywhere
5. Colored-border cards
6. Glassmorphism cards
7. Low-contrast dark mode
8. Repetitive rows of three icon boxes
9. Badges above headlines
10. Lucide icons used as the universal icon language
11. Untouched shadcn UI
12. Fade-in-on-scroll effects
13. Cursor-following beams
14. Buttons that fade on hover
15. Inconsistent spacing
16. Excessive em dashes
17. Generic buzzword copy
18. Decorative serif italic accents
19. The Space Grotesk and Instrument Serif pairing
20. Grain overlays on gradients

Use Kodosi's authored control family, warm charcoal and copper visual system,
spacing tokens, accessible contrast, and product-specific language instead.
